# ENACTUS HTI Organization Hub 🌐

An organization management system for ENACTUS HTI, coordinating social entrepreneurship initiatives, community tasks, impact metrics, and alumni.

## Technology
- Laravel
- React 19 and TypeScript
- Tailwind CSS
- Role-based access control (RBAC)
